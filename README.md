# 🎤 Voice to Text Converter (Python GUI)

A simple and interactive **Voice-to-Text Python application** built using `Tkinter`.  
This app listens to your voice, displays the recognized text in a window, and allows you to save it to a file — all without using the terminal.

---

## 🎯 Features
- 🪄 Graphical User Interface (GUI) — easy to use  
- 🎙️ Real-time voice recognition  
- 🔊 Text-to-speech feedback after each input  
- 💾 Save recognized text to `voice_text_output.txt`  
- ⏹️ Stops automatically when you say **"exit"** or remain silent  
- ⚙️ Works completely offline — no internet or paid APIs needed
